# V4–V14 순차 계획 수정 확인

사용자 요구: 궁극적으로 Viewer 안에서 게임처럼 파리와 상호작용, 모든 환경 통제, 욕구/정서/각성별 뉴런 해석, 외부 게임 입출력 모듈 장착 기반. 실제 게임 모듈은 만들지 않는다. V4부터 V14까지 순차 설계하며 상세 구현 지침을 제공한다.

## 수정 결과

- 로드맵을 V4→V14 고정 순서로 수정했다.
- V4 상태를 소스 기준 구현 진행 중/최종 인수 대기로 정정했다.
- V5–V14 상세 계획 10개를 만들었다. 각 계획에 선행 조건, 파일 책임, 데이터 계약, 세부 구현 순서, 실패 처리, 검사 시나리오, 완료 체크, 인수인계를 포함한다.
- 공통 Viewer/환경/뉴런/외부 I/O 설계와 구현 playbook을 추가했다.
- 이전 로드맵은 history에 보존하고 정본에서 옛 버전 의미를 대체했다.
- README/문서 index 및 역사적 V3 검증 절의 링크를 갱신했다.
